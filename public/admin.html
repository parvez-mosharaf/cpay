Add a BTCPay shop
One BTCPay server, several stores. BTCPay applies the rate itself through the store's rate spread (Store → Rates → add a percentage) — the number here is only so this panel and the payment page can show what the payer will be charged. Set it in BTCPay first, then mirror it here.

The API key itself is never stored here — pick which Edge Function secret holds it, and add that secret in Supabase under Edge Functions → Secrets.

Link styles are chosen by the creator, per link — not here. A shop is a BTCPay store and a cost; creators pick which cost each of their links runs on. Add or disable a shop and their dashboards follow immediately.

Staff access
A moderator signs in at /moderator.html and handles the creators you tick below — their payments, their details, and the "checked" mark. Creators you do not tick are invisible to them: the filtering is in the database, so an unassigned creator's payments never leave it.

A moderator can never change a payment's status or amount, touch a withdrawal, or grant staff access — those stay with you.
